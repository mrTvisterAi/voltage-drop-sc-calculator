# Калькулятор потерь напряжения и токов КЗ (портативный)

Полностью **портативная** программа (один .exe, без установки Python) для расчёта потерь напряжения с учётом трансформатора и токов однофазного короткого замыкания.

## Главные возможности

- **Иерархия по реальному проекту**:
  - ВРУ (вводно-распределительное устройство)
  - Неограниченное количество щитов, питаемых от ВРУ
  - В каждом щите — неограниченное количество отходящих распределительных групп
- Расчёт тока нагрузки, ΔU (В и %), тока однофазного КЗ с учётом трансформатора
- Учёт способов прокладки кабеля (лоток, гофра, канал, ПВХ, стальная труба)
- Сводная ведомость кабелей по всему проекту
- Сохранение / загрузка проектов (JSON)
- Экспорт таблиц в Excel
- **Экспорт однолинейных схем каждого щита**:
  - PDF
  - **DXF** (открывается в AutoCAD / nanoCAD / BricsCAD → «Сохранить как DWG»)

## Портативная версия (без установки)

```bash
pip install -r requirements.txt pyinstaller
pyinstaller --onefile --windowed --name "VoltageDropCalc" main.py
```

Готовый файл: `dist/VoltageDropCalc.exe` — копируете на любой Windows-ПК и запускаете без установки Python.

## Запуск из исходников

```bash
pip install -r requirements.txt
python main.py
```

## Экспорт схем

Для **каждого щита** создаётся отдельный файл:

- **PDF** — для просмотра и печати
- **DXF** — для редактирования в AutoCAD

В схеме:
- шина щита
- условные автоматы (QF)
- отходящие линии с подписями (марка, сечение, длина, ток, ΔU, Iкз)
- рамка и основная надпись
- слои (ШИНА, АППАРАТЫ, ЛИНИИ, ТЕКСТ, РАМКА) — удобно править

Это **упрощённая** однолинейная схема (ориентир ГОСТ 2.702 / 21.608).  
Для официальной проектной документации доработайте в CAD.

**Как получить настоящий DWG:**
1. Откройте `.dxf` в AutoCAD / nanoCAD / BricsCAD
2. Файл → Сохранить как → формат DWG

## Формулы

**Потери напряжения**:
- 1ф: ΔU = 2·I·(R·cosφ + X·sinφ)
- 3ф: ΔU = √3·I·(R·cosφ + X·sinφ)

**Ток однофазного КЗ**: Iкз1 = Uф / Zпетли (Zт + 2·Zкаб + контакты)
