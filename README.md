# Калькулятор потерь напряжения и токов КЗ (портативный)

Полностью **портативная** программа (один .exe, без установки Python) для расчёта потерь напряжения с учётом трансформатора и токов однофазного короткого замыкания.

## Главные возможности

- **Иерархия по реальному проекту**:
  - ВРУ (вводно-распределительное устройство)
  - Неограниченное количество щитов, питаемых от ВРУ
  - В каждом щите — неограниченное количество отходящих распределительных групп
- Расчёт тока нагрузки, ΔU (В и %), тока однофазного КЗ с учётом трансформатора
- Учёт способов прокладки кабеля (лоток, гофра, канал, ПВХ, стальная труба)
- Сводная ведомость кабелей по всему проекту
- Сохранение / загрузка проектов (JSON)
- Экспорт таблиц в Excel
- **Экспорт однолинейных схем каждого щита отдельно** (упрощённый вид, близкий к ГОСТ 2.702 / ГОСТ 21.608 — боковик + шина + автоматы + кабели)

## Портативная версия (без установки)

1. Скачайте готовый `.exe` из раздела [Releases](https://github.com/mrTvisterAi/voltage-drop-sc-calculator/releases) (когда будет собран).
2. Или соберите сами (один раз):

```bash
pip install -r requirements.txt pyinstaller
pyinstaller --onefile --windowed --name "VoltageDropCalc" main.py
```

Готовый файл появится в папке `dist/VoltageDropCalc.exe`. Его можно копировать на любой Windows-компьютер и запускать **без установки Python**.

## Запуск из исходников (для разработчиков)

```bash
pip install -r requirements.txt
python main.py
```

## Экспорт схем

Для каждого щита формируется отдельный PDF с однолинейной схемой:
- шина щита
- вводной автомат
- отходящие линии с обозначениями (марка, сечение, длина, ток, ΔU, Iкз)
- основная надпись в стиле ГОСТ

Это **упрощённая** реализация (не полный CAD). Для официальной проектной документации рекомендуется доработать в AutoCAD / nanoCAD по ГОСТ 2.702-2011 и ГОСТ 21.608.

## Формулы

**Потери напряжения**:
- 1ф: ΔU = 2·I·(R·cosφ + X·sinφ)
- 3ф: ΔU = √3·I·(R·cosφ + X·sinφ)

**Ток однофазного КЗ**: Iкз1 = Uф / Zпетли (Zт + 2·Zкаб + контакты)
