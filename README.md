# Калькулятор потерь напряжения и токов КЗ

Портативная программа на Python для расчета потерь напряжения в кабельных линиях с учетом трансформатора и токов однофазного короткого замыкания.

## Возможности

- Ввод параметров трансформатора (мощность, uk%, потери КЗ, схема соединения)
- Несколько групп/листов (ВРУ + исходящие группы)
- Расчет тока нагрузки, потерь напряжения ΔU (В и %), тока однофазного КЗ
- Учет способа прокладки кабеля (лоток, гофра, канал, ПВХ-труба, стальная труба)
- Сводная ведомость используемых кабелей по проекту
- Сохранение и загрузка проектов (JSON)
- Экспорт результатов в Excel (.xlsx)

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

Программа работает без установки (после установки зависимостей) — достаточно Python 3.8+.

## Структура данных (по ТЗ)

1. Лист ВРУ
2–N. Исходящие группы (до 10)

Колонки группы:
- №, Наименование, № группы, Этаж, Мощность, Напряжение (230/400), cos φ, Ток А, Кол-во кабелей в цепи, Марка, Кол-во жил, Сечение, прокладка в лотке / гофре / канале / ПВХ / стальной трубе, Сумма длин, Материал жилы (медь/алюминий), Длина линии, Приведенная длина, Потеря напряжения, Ток однофазного КЗ.

Итоги по группе: PΣ, средневзвешенный cos φ, ток.

Последний лист — ведомость кабелей:
| Марка кабеля | жил×сечение | в лотке | в гофре | в канале | в ПВХ-трубе | в стальной трубе | Итого длина |

Данные автоматически суммируются по одинаковым параметрам.

## Формулы (упрощенные)

**Потери напряжения (однофазная сеть):**
ΔU = 2 · I · (R · cosφ + X · sinφ) · L

**Трёхфазная:**
ΔU = √3 · I · (R · cosφ + X · sinφ) · L

где R = ρ · L / S (ρ меди ≈ 0.0175, алюминия ≈ 0.028 Ом·мм²/м), X ≈ 0.08 Ом/км (типично для кабелей).

**Ток однофазного КЗ (петля фаза-ноль):**
Iкз1 = Uф / Zпетли
Zпетли ≈ Zт + 2·(Rкаб + jXкаб) (+ контакты)

Параметры трансформатора задаются пользователем.
